# ATM_Projem
C# programlama dili kullanılarak konsol ortamında geliştirilen bu projem; temel bankacılık işlemlerini (Güvenli PIN doğrulama, bakiye sorgulama, para yatırma, para çekme ve çıkış) gerçekleştiren basit düzeyde bir nesne yönelimli (OOP) konsol otomasyonudur.

Kullanıcı Doğrulama Sistemi: Şifre ve hesap numarası doğrulaması ile güvenli giriş akışı.
Dinamik İşlem Menüsü: Kullanıcının yapmak istediği işlemi seçebileceği kullanıcı dostu konsol arayüzü.
Bakiye ve Limit Kontrolleri: Para çekme işlemlerinde yetersiz bakiye kontrolü ve anlık bakiye güncellemeleri.

Kullanılan Teknolojiler
Programlama Dili: C# (.NET Core / .NET Framework)
Çalışma Ortamı: Konsol / Komut Satırı (CMD)
